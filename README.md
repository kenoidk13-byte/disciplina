# Disciplina

<img src="logo.svg" alt="Disciplina" width="320">

Личный тренер в браузере: выбираешь доступные упражнения, вписываешь рабочие веса, ставишь цель — получаешь программу на 2–4 дня в неделю. Дальше Disciplina сама поднимает веса, ротирует упражнения и ведёт историю.

Без сборки, без регистрации, без бэкенда. Всё считается и хранится на устройстве.

## Запуск

```bash
cd ~/disciplina
python3 -m http.server 8765
```

Открыть <http://localhost:8765>.

С телефона в той же Wi-Fi: `http://<IP-компьютера>:8765`
(IP: `ipconfig getifaddr en0`).

## Установка на телефон

- **iPhone (Safari)**: Поделиться → «На экран Домой».
- **Android (Chrome)**: меню → «Установить приложение» / «Добавить на главный экран».

После установки открывается на весь экран, работает офлайн (service worker).

## Как работает

1. **Упражнения.** Отмечаешь всё, что умеешь и хочешь делать. Фильтры по инвентарю и группе мышц. Без инвентаря тоже можно — есть упражнения с весом тела.
2. **Веса.** Для каждого упражнения — рабочий вес и число повторов. Это точка отсчёта, дальше вес растёт сам.
3. **Цель.** Масса / форма / сушка + число тренировок в неделю. От цели зависят подходы, повторы и отдых.
4. **Программа.** Два режима сборки. **Авто** — 2–3 дня фулбоди (всё тело A/B/C) или 4 дня верх/низ (верх A, низ A, верх B, низ B), каждая мышца нагружается 2+ раза в неделю. **Сам** — конструктор: выбираешь группы мышц на каждый день (например, спина + ноги + бицепс), упражнения подбираются под них автоматически. Порядок упражнений в дне — от крупных многосуставных движений к изоляции и мелким группам, пресс в конце.
5. **Тренировка.** День рассчитывается минимум на **50 минут**: сначала добирается отдых, затем — подходы, а при возможности — ещё упражнения из подходящих групп. У каждого упражнения указан **RIR** — сколько повторов остаётся до отказа. Отмечаешь подходы, идёт таймер отдыха, по завершении — итоги: время, тоннаж, новые веса.
6. **Прогресс.** Если все подходы сделаны на верхней границе повторов, вес автоматически растёт на шаг инвентаря (штанга +2,5 кг, гантели +2 кг и т.д.).
7. **Архив.** История сгруппирована по месяцам: дата, день, упражнения, тоннаж. Нажми на тренировку — увидишь все подходы. Нажми на упражнение — откроется его архив: все подходы по датам, лучший вес, тоннаж и график.
8. **Ротация.** При пересборке упражнения выбираются с учётом последних тренировок: недавние не повторяются, нагрузка распределяется по дням. В режиме «Сам» внутри выбранных групп сначала идут базовые движения, потом изоляция. Через 3 недели программа предлагает обновиться сама.

Режим сборки меняется в **Настройки → Сборка дней** или прямо на шаге «Какая цель?».

## Методика

Программа собирается по объёмной модели, а не по фиксированному списку упражнений. Ориентиры взяты из публичных материалов по гипертрофии (Eric Helms / Renaissance Periodization, Jeff Nippard, Brad Schoenfeld, Stronger by Science).

- **Объём.** 10–20 подходов на мышцу в неделю — рабочий диапазон для роста; меньше 10 часто недостаточно, больше 20 редко даёт больше. Косвенная работа от базовых движений считается как 0,25–0,6 подхода (жим → грудь/плечи/трицепс, тяга → спина/бицепс, присед → квадрицепс/ягодицы/бицепс бедра). При 2 тренировках цель снижается до ~70–90%, иначе день не влезает в разумное время.
- **Частота.** Каждая мышца — минимум 2 раза в неделю. Поэтому 2–3 дня собираются как фулбоди, 4 дня — как верх/низ. Это эффективнее одного «дня груди» в неделю при том же объёме.
- **Интенсивность.** База: 1–3 повтора в запасе (RIR), изоляция: 0–2 RIR в последнем подходе. На массе 4×6–10 на базу и 3×10–15 на изоляцию, на сушке — 3×8–12 и 3×12–20, поддержание — 3×6–10 и 3×10–15. Отдых 120 с на базу и 45–75 с на изоляцию.
- **Баланс.** Генератор выбирает упражнения для самых отстающих по недельному объёму мышц, не ставит больше двух базовых на одну мышцу в день и не повторяет упражнение в течение недели, если есть альтернатива. После сборки `balanceVolume()` добирает подходы мышцам ниже нижней границы, не раздувая день выше 75 минут и не превышая верхнюю границу больше чем на 2 подхода.
- **Ротация «Таза».** В слотах на заднюю цепь выбирается самое давно использованное упражнение, а не самое выгодное по объёму. Поэтому варианты (становая, румынская, гиперэкстензия, хип-траст и т.д.) появляются по очереди, а не застревает один.
- **Разгрузка.** Через 6 недель программа предлагает разгрузочную неделю: подходы срезаются на 40% (минимум 2), веса и история сохраняются. Через 7 дней объём возвращается одной кнопкой; следующее предложение — не раньше чем через 6 недель.
- **Прогрессия.** Когда все подходы сделаны на верхней границе повторов, вес растёт на шаг инвентаря (штанга +2,5 кг, гантели +2 кг и т.д.). Упражнения ротируются с учётом последних тренировок.

Панель **«Объём недели»** на экране программы показывает фактические подходы по мышцам, недельную частоту и границы цели — видно, что программа сбалансирована.

## Данные

Хранятся в `localStorage` браузера под ключом `disciplina.v1`.

- **Настройки → Экспорт данных** — скачать JSON-бэкап.
- **Настройки → Импорт данных** — восстановить.
- **Сбросить всё** — удалить безвозвратно.

При очистке данных браузера состояние пропадёт — делай экспорт перед этим.

## Структура

```
disciplina/
├─ index.html            каркас
├─ app.css               стили
├─ data.js               библиотека упражнений, шаблоны дней, цели
├─ app.js                состояние, генератор программ, прогрессия
├─ ui.js                 экраны, роутер, обработчики
├─ sw.js                 офлайн-кэш
├─ manifest.webmanifest  PWA-манифест
├─ icon.svg, icon-*.png  иконки
└─ dev/                  тестовые страницы (в прод не нужны)
```

Демо-режим для проверки интерфейса: `index.html#demo`, `#demo-pick`, `#demo-session` (работает только на пустых данных).

## Проверка

Тестовые страницы в `dev/` открываются на локальном сервере и печатают `RESULT PASS/FAIL`:

| Страница | Что проверяет |
|---|---|
| `dev/smoke.html` | Полный сценарий: онбординг → программа → тренировка → история |
| `dev/onb.html` | Онбординг и сборка на 4 дня |
| `dev/builder.html` | Конструктор дней по группам, включая скудный набор упражнений |
| `dev/duration.html` | Минимум 50 минут и логотип |
| `dev/order.html` | Порядок упражнений: база раньше изоляции, крупные группы раньше мелких, пресс в конце |
| `dev/sheet.html` | Шторка: перетаскивание, инерция, возврат, закрытие тапом |
| `dev/archive.html` | Архив: месяцы, детали тренировки, история упражнения, «Показать ещё» |
| `dev/pick.html` | Поиск упражнений: название, группа, скрытые инвентарём |
| `dev/method.html` | Методика: сплиты, 50 минут, частота 2+, объём в границах, RIR, разгрузка, ротация «Таза», панель объёма |
| `dev/audit390.html` | Переполнение и тап-таргеты (390 px; `?w=320` для узкого экрана) |
